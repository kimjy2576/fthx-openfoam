# OpenFOAM 경로 — 미해결 / 결정 항목

핸드아웃 §6 형식을 따름. Fluent 경로에도 해당되는 항목은 (공통) 표시.

| # | 항목 | 상태 |
|---|---|---|
| O1 | **(공통) closure α·C2 상호배타성** — `closure.air_side()` 의 alpha 와 C2 는 각각 '단독으로' dp 전체를 재현하는 대체 폐합임 (μ·(1/α)·u·W ≡ dp, C2·W·½ρu² ≡ dp). 둘을 동시에 적용하면 구조적으로 dp 2배. OpenFOAM 실측: d+f 동시 16.0 Pa → f 단독 7.88 Pa. **OpenFOAM 은 f=C2 단독으로 확정** (`porous_df`, 테스트 고정). ⚠ Fluent 저널(`exporters.py`)은 viscous·inertial 을 둘 다 set_state 함 — M4 가 closure 와 0.03% 일치한 것은 `try_all` 이 실패를 삼켜 한쪽만 적용됐을 가능성. **Fluent 세션에서 존 속성 덤프로 실제 적용값 확인 필요.** 저유량 스윕은 Re 별 재폐합 필요 | 열림 |
| D1 | **주기 단위셀(D 모드) 메시 성립** — snappy 로 핀 실형상 단위셀이 됨. 배경격자를 공기 bbox(z 0.0575~0.907mm)에 맞추면 다섯 면이 그대로 patch(핀 상면=wall, 나머지=symmetryPlane)가 되어 STL 은 관만 필요. 비등방 배경(704×51×10)이 Fluent 의 z 스윕에 대응. **실측 365,683셀 · 종횡비 3.37 · Mesh OK** (core 추정 375,514 와 2.6%) | 해결 |
| D2 | **추출 j/f 가 상관식과 크게 다름** — CFD j=0.0202 f=0.1806 vs 상관식 j=0.0146 f=0.0171. **1차 정렬 완료**: 코어 단면(x=44/88mm) sampledSurface 프로브 추가 → 코어만 ΔP 32.4 Pa (전체 56.8 의 57%), f 0.181→0.103. 상관식 0.0171 과 여전히 6배. j 는 1.4배. **원인 발견: 입구 속도 오부과** — cell_flow 의 u_max(2.869)를 입구에 그대로 줬으나, 단위셀 입구는 관이 없는 자유단면이므로 V_face(2.0)를 줘야 코어 최소단면에서 u_max 가 재현됨. 잘못 주면 코어가 1.43배 더 빨라져 ΔP ~2배·h 과대. 수정 후 재측정 필요 (수정 전 수렴값: f 0.102, j 0.0286, 효율 0.91). 그래도 차이가 남으면 (a) plain 상관식이 Re_Dc 1773·이 형상에서 부정확한 것이 실제 발견일 수 있음 — D 모드를 도입한 이유 자체 (b) A_o/A_c 정의 재확인 순으로 볼 것 | 열림 |
| D3 | **단위셀 j/f 확정값과 상관식의 3배 차이** — 수렴(237 it) 결과 j=0.0424(상관식의 2.92배), f=0.0566(3.32배). ΔP_core 17.82 Pa, h=181.3 W/m²K. **다만 효율 0.967** (T_out 280.80 vs T_wall 280.15, dT2=0.65K)로 LMTD=5.65 밖에 안 됨 → h 가 수치오차에 민감한 영역. 원인 후보 (a) 등온 핀 전면 가정이 실제보다 강한 냉각 — 단위셀 코어 44mm 가 이 유량엔 너무 김 (b) extract_jf 의 G_max 가 풀사이즈 기준인데 단위셀 실제 최대유속과 다름 (c) 상관식이 실제로 부정확 — D 모드 도입 이유. **Fluent 세션의 같은 단위셀 j/f 와 비교하면 정의 문제인지 물리인지 판별됨** | 열림 |
| D4 | **해결** — 원인은 (1) 체적 열원이 냉매온도를 직접 참조해 관측 저항을 우회 (2) 예측이 core_bbox 를 쓰는데 fvOptions cellZone 은 관 체적을 뺀 영역(13% 작음). hv 를 UA_series/V 로, V 를 `core_volume_m3()`(관 제외)로 통일하여 자기일관화. **실측: 상관식 기준 CFD 2.981 vs 예측 2.971 (+0.3%) · 단위셀 j/f 주입 CFD 6.836 vs 예측 7.501 (−8.9%)** — 양쪽 게이트 통과. j/f 가 3배 달라져도 검증이 성립함을 확인 |
| E1 | **WSL 경로를 Windows python.exe 에 넘기면 실패** — `~/cases/...` 는 `/home/...` 라 Windows 가 모름 (`FileNotFoundError: \\home\\...`). `/mnt/c/...` 도 마찬가지로 Windows 는 못 읽어 `C:\\mnt\\c\\...` 로 오해함. `make_results.py` 의 `winpath()` 가 `/mnt/<d>/` → `<D>:/`, `/home/...` → UNC 로 자동 변환. 케이스 실행은 `~/cases`(빠름), 후처리는 경로 변환 — 이 조합을 유지 | 해결 |
| O2 | **배선 완료** — D→B 주입(`foam/jf_inject.py`)으로 단위셀 j/f 를 포러스·열 계수에 적용 가능. j/f 값이 확정되면 이중계상이 구조적으로 해소됨. 실측(tutorial, jf 주입): ΔP 8.1→25.7 Pa, T_out 291.6→284.0 K, UA≈3.4→9.8 W/K (j/f 3배의 영향이 그대로 반영). **(원문) 관 항력 이중계상** — j/f 상관식은 전체 번들(관 포함) 기준인데 형상은 관을 명시적으로도 해상 → 관 기여가 상관식과 CFD 에 각각 한 번씩 들어감. tutorial 실측: ΔP_CFD 7.88 = 포러스 4.16 + 관 항력·가속 ~3.2 + 덕트 ~0.5. 근본 해법은 멀티스케일 규약대로 주기 단위셀에서 '핀 전용' j/f 를 받는 것 — Fluent 세션의 단위셀 산출물이 나오면 그 값으로 `closure` 를 대체 | 열림 |
| O3 | probe(벤드) 확장 | **air 모드 해결** — 벤드는 덕트 z 범위 밖(z −17~117 vs 덕트 10~90)이라 공기 도메인과 무관. 배경격자는 air_bbox 그대로, 벤드 STL 은 drop. 실측(8코어 수렴) 95,700셀·Mesh OK·UA 8.114 vs 예측 8.038(0.95%)·ΔP 7.900 Pa. cht 모드는 여전히 global_bbox 확장 필요 |
